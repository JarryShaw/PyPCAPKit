NGAP Constant Enumerations¶

This module contains all constant enumerations of NGAP implementations. Available enumerations include:

NGAP_ProcedureCode

NGAP Elementary Procedure Codes [*]

NGAP_ProtocolIE

NGAP Protocol IE Identifiers [†]

Both are automatically generated from pycrate’s compiled NGAP specification rather than an IANA-style registry – see pcapkit.vendor.ngap.procedure_code’s module docstring for why.
