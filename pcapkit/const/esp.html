ESP Constant Enumerations¶

This module contains all constant enumerations of ESP implementations. Available enumerations include:

ESP_Cipher

Encryption Algorithm Transform IDs [*]

ESP_Integrity

Integrity Algorithm Transform IDs [†]

ESP has no algorithm registry of its own: an SA’s algorithms are negotiated by IKEv2, so both enumerations are the corresponding IKEv2 transform ID sub-registries. They live here rather than under an ikev2 package because ESP is the only thing in pcapkit that consumes them.

Both enumerate every transform IANA has registered, which is a much larger set than pcapkit can apply. Which of them ESP actually implements is a separate question, answered by CIPHER_SUITES and INTEGRITY_SUITES.

[*]

https://www.iana.org/assignments/ikev2-parameters/ikev2-parameters.xhtml#ikev2-parameters-5

[†]

https://www.iana.org/assignments/ikev2-parameters/ikev2-parameters.xhtml#ikev2-parameters-7
