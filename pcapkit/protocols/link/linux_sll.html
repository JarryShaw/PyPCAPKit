LinuxSLL - Linux “Cooked” Capture Encapsulation Family¶

pcapkit.protocols.link.linux_sll contains LinuxSLL only, the base class of the Linux “cooked” capture encapsulation family:

LinkType

Class

LINUX_SLL (113)

LinuxSLL1

LINUX_SLL2 (276)

LinuxSLL2

The versions differ in field order and width, so each parses its own header. The base holds what they share: the next-layer dispatch, and link-layer address validation. It has no registry index, so its __index__ raises.

Bases: Link[_PT, _ST], Generic[_PT, _ST]

Base class of the Linux “cooked” capture encapsulation family.

The versions differ in field order and width, so this base holds only the next-layer dispatch they share. See Selecting a Version for the labels that select a version.

Selecting a Version¶

The family name selects either version, and each version’s own name selects that version only, as IPv4 and IPv6 do under IP. 'LinuxSLL' is in both versions; 'LinuxSLL1' in a v2 layer is False. String == does not expand a key, so v1 == 'LinuxSLL' is False while 'LinuxSLL' in v1 is True.
