Root Protocol¶

pcapkit.protocols.protocol contains Protocol, an abstract base class with pre-defined utility arguments and methods. Inherit it directly only to create a new protocol stack; a new protocol in an existing layer subclasses that layer’s base class – Link, Internet, Transport or Application – instead; see Customisation & Extensions. The built-in protocol families, those layer classes included, derive from ProtocolBase, whose metaclass is ProtocolMeta; both are listed under Internal Definitions below.

Changed in version 1.5.0: Constructing a protocol with a keyword that none of its signatures declares raises UnsupportedCall, where it was discarded (#617). A next layer captured shorter than its header is kept as Raw, where it was parsed with zero-filled fields (#1170).

Bases: ProtocolBase, Generic[_PT, _ST]

User-facing abstract base class for third-party protocols.

Inherit it directly only to create a new protocol stack; a new protocol in an existing layer subclasses that layer’s base class instead; see Customisation & Extensions. The built-in protocol families do not derive from this class but from ProtocolBase, whose metaclass is ProtocolMeta.

Register a new protocol class.

Notes

The fully qualified class name of the new protocol class should be {protocol.module}.{protocol.name}.

Parameters:

Raises:

classmethod from_data(data, **kwargs)¶

Create protocol instance from data.

data may be the dict that Info.to_dict returns, which carries the metadata the rebuild reads: __next_name__ and __next_type__, which the payload is dispatched on, __short_read__ and __short_width__, and, for IPv6, the extension header chain under __exthdr__. A hand-written dict without them rebuilds no payload (nor IPv6 extension header) and cuts no short read back; nothing is guessed from its other keys (see _make_payload(), #2003).

A header the capture cut short, as __short_read__ records, is cut back and read at the width __short_width__ records, so the rebuild parses the octets captured as the capture did (#2703): it holds the values its parse read, not those make() fills in past the cut (#2761), and the Raw next layer that parse left (#2717). Inside a payload _make_payload() rebuilds, which gives only its octets, the header made is read instead.

Parameters:

  • data (_PT | dict[str, Any]) – Protocol data.

  • **kwargs (Any) – Construction keywords that data does not carry, such as the num and header of Frame, or the num, sct and ctx of PCAPNG. They take precedence over the keywords _make_data() returns.

Return type:

Self

Returns:

Protocol instance.

Raises:

UnsupportedCall – If any of kwargs matches no parameter of the protocol, as for a direct construction.

abstractmethod make(**kwargs)¶

Make (construct) packet data.

Parameters:

**kwargs (Any) – Arbitrary keyword arguments.

Return type:

_ST

Returns:

Curated protocol schema data.

Note

The **kwargs absorbs the keywords Protocol.__post_init__ hands to the parse as well as the construction, so an implementation need not declare every keyword it is called with. A caller’s keyword that no signature declares still raises UnsupportedCall from Protocol.__init__ (#617).

Warning

Calling this method directly is not checked, and discards an undeclared keyword silently. The check lives in Protocol.__init__, the one place the keywords converge, so it covers SomeProtocol(...) and its pack(), but not object.__new__(cls).make(**kwargs), as HTTP.make calls its versioned implementation. Construct through the constructor to get the check.

unpack(length=None, **kwargs)¶

Unpack (parse) packet data.

Parameters:

  • length (int | None) – Length of packet data.

  • **kwargs (Any) – Arbitrary keyword arguments.

Return type:

_PT

Returns:

Parsed packet data.

Notes

The special keyword argument __packet__ passes the global packet data to underlying methods, for when the current instance does not have it.

A self.__header__ already set, by from_schema() or by the pack() call of __post_init__(), is kept, unless it holds raw bytes where parsing its packed octets yields a schema – e.g. a raw option given to make(), directly or inside a data model – which read() cannot consume; it is then replaced by the parsed one (#1312).

A header from_data() rebuilds from a short read is parsed from the octets captured, its warnings discarded, and given its data model’s __short_read__ before read() runs, as the record of a cut those octets may not show (#2761).

Raises:

ProtocolError – If the made header holds raw items and its packed octets do not parse, either as a schema or by read(). The message carries the original error’s, which is also chained as __cause__.

Changed in version 1.6.0: A raw item that make() takes from inside a data model, such as the one from_data() passes on, is replaced too, rather than reaching read() (#2725).

pack(**kwargs)¶

Pack (construct) packet data.

Parameters:

**kwargs (Any) – Arbitrary keyword arguments.

Return type:

bytes

Returns:

Constructed packet data.

Notes

The special keyword argument __packet__ passes the global packet data to underlying methods, for when the current instance does not have it.

The octets are built from kwargs alone, through make(); the instance’s state is not read, so a bare SomeProtocol(...).pack() returns a default header, not the instance’s octets, which data holds.

Nor is that state written. Once the instance is parsed or constructed, the header is made on a shallow copy (see _packing_target()), so schema, info and anything make() sets, such as TCP.connection, still describe that packet. Only the call __post_init__() makes to construct the instance keeps the header, for unpack() to read back.

When from_data() rebuilds a header the capture cut short, that call cuts it back to the octets captured, through __short_read__ and Schema._cut_short_read (#2703). __post_init__() then drops that header, so unpack() parses the octets back and the rebuild holds the values its parse read, not those make() filled in past the cut (#2761).

Changed in version 1.5.0: Calling it no longer replaces the instance’s __header__, which left schema disagreeing with info (#1769).

static resolve_index(name, default=None, *, namespace, reversed=False)¶

Resolve a name for an enumeration field of make().

A field of make() that holds an enumeration takes a member or an int code, and refuses a name (#2594). This resolves a name against a namespace given explicitly, so that its result can be passed on:

>>> from pcapkit.const.reg.ethertype import EtherType
>>> from pcapkit.protocols.link.ethernet.protocol import Ethernet
>>> code = Ethernet.resolve_index('Address_Resolution_Protocol',
...                               namespace=EtherType)

__layer__: Literal['Link', 'Internet', 'Transport', 'Application'] | None¶

Layer of protocol, can be one of Link, Internet, Transport and Application. For example, the layer of Ethernet is Link. However, certain protocols are not in any layer, such as Raw, and thus its layer is None.

__proto__: DefaultDict[int, ModuleDescriptor[ProtocolBase] | Type[ProtocolBase]]¶

Protocol index mapping for decoding the next layer; see self._decode_next_layer and self._import_next_layer. Each value is a ModuleDescriptor naming the module and class, or a ProtocolBase subclass.

__keywords__: frozenset[str] | None¶

Construction keywords this protocol takes out of **kwargs by name rather than declaring as a parameter, as IPv6_Ext.read does with alias. _declared_keywords() reads signatures, which miss such a name, so the construction check of __init__() accepts only those listed here, unioned over the MRO. Prefer a declared parameter, which also documents the keyword (#617).

None skips the check, for a dispatcher whose real signature is chosen at call time: HTTP.make declares only version and forwards the rest to HTTPv1.make or HTTPv2.make. A protocol that skips the check discards an unknown keyword silently. Unlike a set, None is not inherited, so HTTPv1 and HTTPv2, which declare their keywords in full, stay checked.

__own_make_keywords__: bool¶

Whether the parameters of this class’s own make() are accepted only while that make is the one in use. By default _declared_keywords() takes every make in the MRO. A base whose subclasses override make without forwarding sets this, so its keywords are refused for them rather than accepted and dropped, as IPv6_Ext does for len and data (#2286). Not inherited, and __keywords__ and the other construction methods are unaffected.

_make_index(value, namespace, *, bits, name, alias=None)¶

Resolve the code given for an enumeration field of make().

The field takes a member of namespace or an int code, and either resolves with namespace’s get(). A name is refused rather than looked up, so a caller holding one resolves it first, with resolve_index() (#2594). The code is checked as _make_uint() checks an integer, so a bool passes only for a one-bit field (#2617): the field’s width decides what is refused, not the enumeration’s range.

Parameters:

  • value (Any) – the value given for the field

  • namespace (Type[_ET]) – the enumeration the field holds

  • bits (int) – width of the field, in bits

  • name (str) – name of the field, for the error message

  • alias (str | None) – prefix of the error message, for a caller whose alias raises before read() sets it; alias by default

Return type:

_ET

Returns:

What namespace’s get() resolves value to. For most registries that includes an unassigned code, as the Unassigned or Reserved member their _missing_ builds. Where get raises ValueError for a code the field carries, as a closed enumeration does, the code itself comes back as an int, so that the field is rebuilt as captured.

Raises:

ProtocolError – If value is not an int (a name among them), is a bool for a field wider than one bit, is negative, or does not fit in bits bits. The message names alias.

Changed in version 1.6.0: Takes the enumeration and the width of the field, in place of the default, namespace, reversed and pack arguments, refuses a code the field cannot carry, and refuses a name rather than resolving it against an enumeration inferred from the calling method’s frame (#2594).

classmethod _make_payload(data)¶

Create payload from data for protocol construction.

The payload’s type and name are __next_type__ and __next_name__. If either is missing or None, or data holds nothing under __next_name__, the payload is a NoPayload, as for a protocol with no next layer; otherwise Protocol.from_data builds it.

Info.to_dict carries both keys, so data rebuilt from such a dict dispatches as the info did. A hand-written dict must carry them too, as it must __short_read__ and, for IPv6, __exthdr__: the payload is never guessed from the other keys of data (#2003).

The payload is built one layer further into the frame, as _parse_next_layer() counts it, so a rebuild stops at FRAME_LAYER_LIMIT where the parse did (#1610). The payload’s parse reports nothing, the limit included: this protocol’s own parse goes over the same octets, so the rebuilt frame reports each warning, and each error a next-layer fallback absorbs, once, as the parsed one did (#2711).

Parameters:

data (Data) – protocol data

Return type:

ProtocolBase

Returns:

Payload for protocol construction.

_packing_target()¶

Return the instance that pack() makes its header on.

Return type:

Self

Returns:

static _parse_next_layer(klass, file_, length, **kwargs)¶

Parse the next layer, or keep it as raw octets if its header was not captured.

Parameters:

  • klass (Type[ProtocolBase]) – next layer protocol class

  • file_ (bytes) – payload of the current layer

  • length (int) – valid (non-padding) length

  • **kwargs (Any) – keyword arguments for the next layer’s constructor

Return type:

ProtocolBase

Returns:

Instance of klass, or of Raw when fewer octets were captured than its header needs, or when it is past FRAME_LAYER_LIMIT.

Note

Schema.unpack zero-fills a field the stream ends inside, so a header parsed from too few octets is filled with values that were never on the wire, and from_data rebuilds them (#1170). Such a payload is kept as Raw instead, as an unparseable one is.

The captured octets are the first length of file_, or all of it when it holds fewer, as a truncated capture does. They are short of the header when there are fewer than the next layer’s __length_hint__, unless the header it parsed, length octets long, fits in them anyway: for a variable-length header such as L2TPv2 the hint is the longest form rather than the shortest. A next layer that reports no hint is kept as parsed.

The warnings of a parse that may be replaced are held until that is known, then:

  • replaced as short – dropped, since they describe a header the result does not have: packet length < 0 twice for an Ethernet frame of 10 octets (#1580);

  • kept – reported as the parse ends, inside the guard that catches them under an error filter; a layer kept with its header cut short still warns;

  • raised – dropped when beholder(), which wraps _import_next_layer(), replaces the layer, whose error reports the failure (#2308); otherwise reported as the error leaves.

Under beholder a layer is held however much was captured, since one that raises is replaced at any length (#2516), so a kept layer’s warnings follow those of the layers it carries. Outside it, a layer captured at least as long as its hint cannot be replaced, and is parsed holding nothing, even inside one that holds.

A layer past FRAME_LAYER_LIMIT in its frame is not parsed: it and the rest of the frame are kept as Raw, marked _past_layer_limit, with one ProtocolWarning (#1610).

Warns:

ProtocolWarning – If the next layer is past FRAME_LAYER_LIMIT.

Some layers add steps of their own: Internet the EXTENSION_HEADER_LIMIT bound and IGMP’s dispatch, Transport a family base’s dispatch, and IPv6 the walk drawn under The Extension Header Walk.

Layers per Frame¶

A frame is dissected to at most FRAME_LAYER_LIMIT layers of its protocol chain, counted from the first layer the frame record carries, through tunnels, VLAN tags and IPv6 extension headers alike. What follows is kept as Raw, with one ProtocolWarning (#1610), and is marked _past_layer_limit, so the default engine’s TCP reassembly and flow tracing do not read a TCP segment there back out, as they do one the TCP parser rejected (#1518). A protocol constructed from its own octets is not counted itself, so the count starts at the first layer it dissects. One chain of extension headers is also bounded on its own, by EXTENSION_HEADER_LIMIT. The pyshark, scapy and pypcapfile engines dissect with their own parsers, which do not apply the frame’s layer bound (#1609). The dpkt toolkit reads what dpkt decodes, which applies neither bound.

Value Helpers¶

A protocol reads and makes its field values through the helpers Protocol carries, rather than through copies of its own (#2614). A maker checks a caller’s values through them before packing, and raises ProtocolError for one its field cannot carry rather than masking it (#2617):

  • an unsigned integer through _make_uint(), which takes a bool for a one-bit field only;

  • a two’s-complement integer through _make_sint(), the inverse of _read_sint();

  • the octets of a fixed-size field through _make_octets(), which refuses any other width rather than padding or cutting it (#2676). A value taken from a model of a cut capture goes through _fill_short_read() first, which zero-fills just the octets the cut left out, for the rebuild to cut back.

_uint_size() counts the octets a variable-width integer needs, and pad_length() the padding that takes a length to an alignment boundary.

Sets self.__schema__ and self.__data__ on the subclass and, if code is given, registers it into the next-layer dispatch registry (or registries) code names, e.g. Link.__proto__.

Notes

An omitted schema or data is the class of the subclass’s own name in the schema or data module beside the protocol module defining it, as L2TP finds L2TP (#2534), else Raw or Raw.

Dispatch registration is opt-in, like the engine=/protocol=/ fmt= keywords of Engine, Reassembly, TraceFlow and Dumper. Every built-in protocol omits code: the built-in dispatch tables (e.g. Link.__proto__) are literal assignments in each layer module. A class defined without code can be registered later through the owning class’s register() or the matching register_* helper in pcapkit.foundation.registry.protocols.

code accepts:

  • a single enum member, whose type determines the destination registry (or registries) – e.g. any EtherType member always means Link, and any LinkType member means both Frame and PCAPNG;

  • a dict mapping a destination class to a key, for a key that cannot name its own destination – a raw int port, for instance, is ambiguous between TCP and UDP, and must use this form;

  • an iterable mixing either of the above, to register the same class into several registries from a single declaration – e.g. a L2TP subclass reachable both by its IP protocol number and by a UDP port.

The mapping form is accepted even where the key’s type could be inferred. An enum member whose type names no known destination raises RegistryError rather than guessing.

pcapkit.protocols.protocol.OUT_OF_BAND_KEYWORDS¶

Construction keywords that name no field. Protocol.__init__ or the schema layer consumes them, not make. No signature declares them, so _declared_keywords() takes them from here.

packet is injected by the library: Protocol.__init__ puts packet=self.packet.payload into every parsed _info, which the default Protocol._make_data (data.to_dict()) carries into the keywords Protocol.from_data rebuilds from. Refusing it would break from_data for every protocol whose make lacks it, starting with NoPayload. Where it is a real field, as the packet type of HIP.make, listing it here only stops it being refused.

Methods a construction keyword may be for. Protocol.__post_init__ passes the same **kwargs to pack (and so make) and unpack (and so read).

pcapkit.protocols.protocol._declared_keywords(cls)[source]¶

Collect every keyword the protocol cls declares a parameter for.

Parameters:

cls (type) – Protocol class to inspect.

Return type:

frozenset[str] | None

Returns:

Names of every keyword-acceptable parameter declared by any of _KEYWORD_CONSUMERS anywhere in the MRO of cls, plus every entry of Protocol.__keywords__ found there, plus OUT_OF_BAND_KEYWORDS. None if cls itself sets __keywords__ to None, meaning its keywords cannot be enumerated and are not to be checked – inherited None does not count, as Protocol.__keywords__ explains.

The union is wider than the signature of cls.make: Protocol.__post_init__ hands one **kwargs to both the construction and the parse, so a keyword read declares travels through make too, as extension of HIP.read does.

The walk covers the whole MRO, not the most derived override of each method, so a subclass forwarding to its parent keeps the parent’s keywords. The exception is a class that sets Protocol.__own_make_keywords__: its make counts only while no subclass overrides it (#2286).
