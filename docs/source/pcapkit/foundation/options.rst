Extraction Options
==================

.. module:: pcapkit.foundation.options

:mod:`pcapkit.foundation.options` contains the options classes
:class:`~pcapkit.foundation.extraction.Extractor` and
:func:`~pcapkit.interface.core.extract` take as ``dump``, ``reassembly``,
``traceflow`` and ``stream``, one per feature. :mod:`pcapkit` and
:mod:`pcapkit.interface` export them.
